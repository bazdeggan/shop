КАК ПРАВИТЬ МАГАЗИН
Всё хранится в файле data.json. Открой его на GitHub, нажми карандаш (Edit), поправь и нажми Commit changes.
Через 1-2 минуты сайт обновится.

В "shop": "tg" - Telegram менеджера без @ (сюда идут заказы), "name" - название, "currency" - валюта.
"categories" - список категорий. Название категории в товаре должно совпадать с ней буква в букву.
Товар: {"id":"p7","name":"Название","price":20,"cat":"Жидкости","img":"img/p7.jpg","stock":true,"rating":4.5}
 - id у каждого товара свой, не повторяется
 - stock: true - в наличии, false - нет
 - между товарами ставь запятую, после последнего - не ставь
 - кавычки только прямые "

ФОТО: на странице репозитория Add file > Upload files, перетащи папку img с картинками (лучше до 800 пикселей).
В товаре пиши "img":"img/имя-файла.jpg" (регистр букв важен).
